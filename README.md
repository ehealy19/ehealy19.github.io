# ehealy19.github.io

Lizzie Healy's portfolio, built with [Quarto](https://quarto.org) and hosted on GitHub Pages at <https://ehealy19.github.io>.

## Everyday tasks

| I want to… | Do this |
|---|---|
| Preview the site | In Terminal, from this folder: `quarto preview` |
| Publish changes | `quarto render`, then commit and push (GitHub Pages serves the `docs/` folder) |
| Edit a project's text | Open `projects/<name>/index.qmd` and change the `description:` (the card and the project page both use it) |
| Mark draft text as reviewed | Delete the `review: true` line in that project's `index.qmd` |
| Feature a project on the home page | Add `featured: true` to its `index.qmd` (remove it from another to keep three) |
| Add a project | Copy any folder in `projects/`, rename it, replace the files, edit `index.qmd`. For the card image, add a `thumb.jpg` (16:10, about 640 px wide) |
| Add your headshot | Save it as `assets/headshot.jpg` (portrait, about 800 × 1000 px) |
| Add your resume | Save it as `assets/resume.pdf` |
| Fill in your job | Edit the Experience section in `index.qmd` |
| Change colors or fonts | `:root` block at the top of `styles.css`, plus `assets/theme.scss` |

## How a project page is defined

Every field lives in the front matter of `projects/<name>/index.qmd`:

```yaml
title: "Project title"
description: >-
  One or two sentences shown on the card and at the top of the page.
categories: [Data Science]      # Data Science | Economics | Mathematics | Computer Science
date: 2025-04-30                # used only for sorting (newest first)
image: thumb.jpg
course: "DSAN 5300"
course-name: "Optional full course name"
term: "Spring 2025"
team: "Team of 4"
kind: "Report + poster"         # label on the card image
tools: ["XGBoost", "Regression"]
materials:
  - label: "Report"
    file: report.pdf            # a file in this folder…
    type: pdf                   # pdf | site | code | link
  - label: "Project site"
    url: https://example.com    # …or a web address
    type: site
featured: true                  # optional
review: true                    # optional: shows a "draft text" label
```

Anything you write below the front matter appears under the description on the project page.

PDFs show inline on desktop and as a button on phones. Live sites load only when a visitor clicks "Load live preview", which keeps pages fast.

## Folder map

```
_quarto.yml              site settings, navbar, footer
index.qmd                home page
projects.qmd             filterable project list
resume.qmd               resume viewer
styles.css               all custom styling
assets/                  site.js, theme.scss, logo.svg, headshot.jpg, resume.pdf
_card-listing.ejs        project card template
_filters/project-page.lua  builds each project page from its front matter
projects/<name>/         index.qmd, thumb.jpg, PDFs, site/ or code/ folders
  originals/             source .pptx/.docx files (not published)
docs/                    rendered site, generated by `quarto render`
```
